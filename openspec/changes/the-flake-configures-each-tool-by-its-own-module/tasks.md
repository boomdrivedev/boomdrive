# Tasks

Build the tasks in order. A task is true once the check it names passes, run as it names it. The groups are headings, for reading.

- Every case evaluates against no store, as `nix/check.sh` does, with core.41's neutral names. No task builds a package, writes to the store, or reaches the network but to lock an input, which `nix flake lock` does in the devenv shell, outside the sandbox.
- Tasks 1.1 to 1.3 each need a release tag of a tool whose flake gives its modules (design, Dependencies). Where a tool has none yet, the task waits for its release, and no module is carried in its place (design Decision 1).
- No task adds a crate, a tool or a tracked file type (core.7, core.8). The runner's code does not change. Nothing outside the paths proposal.md's Touches lists is changed.
