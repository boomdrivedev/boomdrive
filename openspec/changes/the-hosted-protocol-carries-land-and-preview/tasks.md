# Tasks

Work through the tasks in order. A task is true once the check it names passes, run as it names it. The groups are headings for reading.

- Version 1's files never change (core.42): a task that would edit a file under `protocol/v1/` is wrong. Version 2 changes only as design Decisions 1 to 4 say.
- The runner's own carrying of a land and of a preview does not change (core.53, core.55): no file of `crates/boomdrive/src/` changes.
- Every test runs on the crate's fakes, in a temporary folder, with neutral names and paths (core.41). No task runs a tool.
- No line the runner says, and no failure a check gives, names a value of a tool's answer: paths alone (core.11).
- Each file's documentation follows the code it describes, in the task that changes that code: no word says version 2 names no land or no preview.
- Record 0037's amendment and the details of core.27, core.42, core.53 and core.55 are written with this change. A task that relies on a choice the design names cites its Decision.
