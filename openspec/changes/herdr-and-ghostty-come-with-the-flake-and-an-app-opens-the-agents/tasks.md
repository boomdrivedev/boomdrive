# Tasks

Build the tasks in order. A task is true once the check it names passes, run as it names it. The groups are headings, for reading.

- Every evaluated case runs against no store, as `nix/check.sh` does, with core.41's neutral names. No task builds a package, writes to the store, or reaches the network, but to lock herdr's input, which `nix flake lock` does in the devenv shell, outside the sandbox.
- Every sh case runs stubs of herdr, Flume, `osascript`, `uname` and `id` in scratch folders, as `nix/tests/activate.sh` does. No task runs a real herdr, Flume, Ghostty or `osascript`.
- No task adds a crate, a tool of the gate or a tracked file type (core.7, core.8). The runner's code does not change. Nothing outside the paths proposal.md's Touches lists is changed. core.md's details were amended in the commit that wrote this change, and no task changes them.
