# Tasks

Work through the tasks in order. A task is true once the check it names passes, run as it names it. The groups are headings for reading.

- crew's descriptor of `repositories.rec` is crew's own, as `plugin/lib/runner.py` holds it at crew's main `323c77fb`. This repository copies it byte for byte and changes nothing of it (design Decision 3).
- Every test runs in a temporary folder or on the scratch host, with neutral names and paths (core.41), and reaches no network (core.4).
- No task adds a crate, a tool, a tracked file type, a configuration key, a field of `report.json` or a message of the protocol (core.7, core.8, core.17, core.36, core.42). Nothing outside the files proposal.md's Touches lists is changed.
- No code outside `crates/boomdrive-crew` names crew, `repositories.rec` or a partition (core.2). A task that relies on a choice the design names cites its Decision.
