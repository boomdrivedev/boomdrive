# Tasks

Work through the tasks in order. A task is done once the check it names passes, run as it names it. The groups are headings for reading; the verify stage runs the repository's whole checks once every task is done.

- Each name a task replaces takes design Decision 1's neutral name for its role, and each quote design Decision 4's citation. No file of this change, and no commit, names a value it replaces.
- A Rust file a task edits is formatted with `devenv shell -- cargo fmt -p <crate>`.
- No task adds a check, a test, a task, a crate, a tool or a tracked file type, and no rule in `docs/architecture/` changes.
