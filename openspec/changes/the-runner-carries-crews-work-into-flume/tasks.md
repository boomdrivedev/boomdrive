# Tasks

Build the groups in order. Each group stands on the ones before it, is one session's work for an agent that has read this change (proposal, design, specs) and its Task notes, and ends green on the moon tasks it names. A task is true once the moon task it names passes, run as it names it.

- Run each check as `devenv shell -- moon run <project>:<task>`, or through sluice while iterating, as CLAUDE.md says.
- `the-runner-keeps-its-repositories` is built and on `main` (design, *What this change rests on*, 1). Where something it gives is missing when a task needs it, stop short with `flume needs --found`, naming it.
- Tests reach no network, run no real Flume, sluice or herdr, and touch no configuration or data of the user's (design Decision 18). Every git call a test makes runs under the scratch environment of `crates/flywheel/tests/common`, every state repository is a bare repository the test makes, and every tool is a fake behind a trait or a stub program the test writes into its own temporary directory.
